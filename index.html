Security status — read before using

Not yet quantum-resistant. This prototype currently uses SHA-256 for block hashing and has no post-quantum wallet signatures, distributed consensus, peer-to-peer networking, or real native coin. The next engineering phase is to integrate and test a standardized post-quantum signature scheme such as ML-DSA, then obtain an independent security review.

Do not enter real passwords, seed phrases, private keys, or funds. This prototype is for learning and testing only.
